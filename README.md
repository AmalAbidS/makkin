Makkin (مكّن) 🚀

Empowering talent through AI-driven job matching

Makkin is an AI-powered job matching platform developed as a final training project at EVC, designed to bridge the gap between job seekers and the right career opportunities.

At its core, Makkin leverages AI and NLP technologies to analyze CVs, understand skills, and intelligently match candidates with relevant job roles. An integrated AI chatbot evaluates resumes, provides clear matching insights, and helps users better understand their strengths in today’s competitive job market.

Tech Stack

Frontend: HTML

Backend: Python

Data Handling: JSON

AI & NLP: OpenAI API (CV evaluation & chatbot intelligence)

Key Features

🎯 Skill-based job matching for more accurate career alignment

🤖 AI-powered CV analysis chatbot with scoring and insights

🔍 Smart job recommendations tailored to each user profile

⚡ Lightweight, simple, and scalable architecture
